# Vendored upstream configuration

`home-assistant-voice.yaml` is the ESPHome configuration of the
[Home Assistant Voice Preview Edition](https://github.com/esphome/home-assistant-voice-pe) at commit
`dc2b9b72657bd5b44812ab184c958a29cda5a7ac` ("bump to ESPHome release 2025.7.2"), copied here so builds are reproducible.

Changes from upstream (and only these):

- the `external_components` entry for `voice_kit` points at that commit instead of the moving `dev` branch, with
  `refresh: never`
- the sound-file URLs point at that commit instead of `raw/dev/`
- a header comment saying so

`../hermes-jarvis.yaml` layers this project's changes on top. Do not edit this file for behaviour changes.
