Flash Hermes JARVIS

Firmware for the Home Assistant Voice Preview Edition. Version __VERSION__.

1. Connect the device

Plug the Voice PE into this computer with a USB cable (the USB-C port on the side), then:

This browser cannot flash devices. Use Chrome or Edge on a desktop computer. Flashing needs a secure (https) page.

Pick the device's serial port in the browser prompt. Flashing takes about a minute. When it finishes you will be asked for your Wi-Fi name and password.

2. Adopt it on the machine that runs hermes-jarvis
  1. Wait until the device's ring is idle after it joins Wi-Fi.
  2. Run hermes-jarvis adopt. It finds the device and gives it a private encryption key.
  3. Run hermes-jarvis doctor, then hermes-jarvis run.

Flashing replaces the current firmware. To go back to the stock Home Assistant firmware, use the official installer. Based on the Home Assistant Voice PE firmware (ESPHome). Not affiliated with Nabu Casa or Home Assistant.
